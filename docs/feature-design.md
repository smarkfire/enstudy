# EnStudy - 英语学习APP 功能设计文档

## 1. 产品概述

### 1.1 产品定位
EnStudy 是一款基于图片识别的智能英语学习工具，帮助用户将学习笔记、教材截图中的生词和短语快速转化为记忆卡片，并通过游戏化复习机制巩固记忆。

### 1.2 目标用户
- 正在自学英语的中文用户
- 有阅读英文材料习惯的学习者
- 希望通过标记方式高效积累词汇的用户

### 1.3 核心价值
- **零门槛录入**：拍照/截图即可生成卡片，无需手动输入
- **智能识别**：自动识别用户标记内容，并补充重要知识点
- **游戏化复习**：将枯燥的背诵变成趣味小游戏
- **科学记忆**：基于间隔重复算法动态调整复习节奏

## 2. 功能模块设计

### 2.1 模块一：图片上传与智能解析

#### 2.1.1 功能描述
用户上传英语学习相关的图片（教材截图、笔记照片等），系统通过千问多模态模型（qwen3.5-omni-flash）直接分析图片内容，识别文字、标记和知识点，将其转化为记忆卡片。

#### 2.1.2 功能清单

| 功能项 | 说明 | 优先级 |
|--------|------|--------|
| 图片上传 | 支持从相册选择或拍照上传 | P0 |
| 多模态图片识别 | 千问多模态模型（qwen3.5-omni-flash）直接分析图片，识别文字、标记和知识点 | P0 |
| 解析方式选择 | 图片上传后选择"智能识别"或"自定义要求"两种解析方式 | P0 |
| 智能内容补充 | AI 自动分析图片内容，补充重要的单词、短语、语法点 | P1 |
| 自定义解析要求 | 用户输入文字/语音要求，AI按需解析；支持快捷标签（只提取动词、提取所有生词、提取固定搭配、每个词2个例句、按难度分级） | P1 |
| 卡片预览与编辑 | 用户可预览生成的卡片，手动增删改 | P0 |
| 批量保存 | 确认后将卡片保存到本地库 | P0 |

#### 2.1.3 标记识别规则
千问多模态模型可直接识别图片中的标记内容，无需本地像素分析：
- **高亮标记**（黄色/彩色背景）：识别为"重点生词"
- **下划线**：识别为"需要掌握的短语"
- **圈画**：识别为"重要语法点或表达"
- **划线标注**：识别为"用户不认识的单词"
- **删除线/叉号**：识别为"已掌握，跳过"
- **无标记但AI判断重要**：标记为"推荐学习"

#### 2.1.4 卡片数据结构

```
Card {
  id: string              // 唯一标识
  type: "word" | "phrase" | "grammar"  // 卡片类型
  content: string         // 原文内容（单词/短语/语法点）
  translation: string     // 中文翻译
  phonetic: string        // 音标（单词类型）
  example: string         // 例句
  exampleTranslation: string  // 例句翻译
  source: string          // 来源图片ID
  tags: string[]          // 标签（如：商务英语、日常口语等）
  difficulty: 1-5         // 难度等级
  createdAt: datetime     // 创建时间
  reviewCount: number     // 复习次数
  correctCount: number    // 正确次数
  nextReview: datetime    // 下次复习时间
  interval: number        // 复习间隔（天）
  easeFactor: number      // 难度因子（SM-2算法）
  status: "new" | "learning" | "review" | "mastered"  // 学习状态
}
```

### 2.2 模块二：游戏化复习

#### 2.2.1 功能描述
基于记忆卡片，设计多种小游戏形式进行复习，配合每日打卡机制和积分系统，激励用户持续学习。

#### 2.2.2 游戏类型

| 游戏名称 | 玩法说明 | 训练目标 |
|----------|---------|---------|
| 单词消消乐 | 屏幕显示多个卡片，将单词与释义配对消除 | 词义记忆 |
| 拼写挑战 | 给出中文释义，用户输入英文拼写 | 拼写能力 |
| 听力选择 | 播放单词发音，选择正确释义 | 听力理解 |
| 填空达人 | 在例句中挖空，填入正确单词 | 语境应用 |
| 速度对决 | 限时内尽可能多地判断词义正误 | 反应速度 |
| 短语重组 | 将打乱的短语单词排列成正确顺序 | 短语掌握 |
| 单词射击 | 单词从屏幕上方掉落，点击正确释义的靶心射击消除 | 词义+反应 |
| 疯狂打地鼠 | 地鼠洞中弹出单词，快速点击对应中文释义的地鼠 | 快速识别 |

#### 2.2.3 积分与等级系统

**积分规则：**
- 每日打卡：+10 分
- 完成每日复习任务：+20 分
- 游戏正确答题：每题 +2 分
- 连续答对加成：连续5题 +5，连续10题 +10
- 完美通关（零失误）：+30 分

**等级系统：**
| 等级 | 所需积分 | 称号 |
|------|---------|------|
| 1 | 0 | 英语小白 |
| 2 | 100 | 初学乍练 |
| 3 | 300 | 渐入佳境 |
| 4 | 600 | 小有所成 |
| 5 | 1000 | 学有所长 |
| 6 | 1500 | 游刃有余 |
| 7 | 2200 | 出口成章 |
| 8 | 3000 | 学富五车 |
| 9 | 4000 | 登峰造极 |
| 10 | 5500 | 英语大师 |

#### 2.2.4 每日任务系统
- 每日复习：复习到期的卡片（系统根据算法推送）
- 每日游戏：完成至少1局游戏
- 每日新卡：学习至少5张新卡片
- 连续打卡奖励：连续7天 +50，连续30天 +200

#### 2.2.5 提醒机制
- 每日固定时间推送复习提醒（用户可自定义时间）
- 有到期卡片未复习时，额外提醒
- 连续打卡即将中断时，提醒

### 2.3 模块三：智能复习调度

#### 2.3.1 功能描述
基于 SM-2 间隔重复算法，结合用户答题表现，动态调整每张卡片的复习时间和频率。

#### 2.3.2 算法设计（SM-2 改进版）

**复习质量评分（0-5）：**
| 评分 | 含义 | 说明 |
|------|------|------|
| 0 | 完全不认识 | 看到后毫无印象 |
| 1 | 有印象但想不起来 | 知道学过但记不住意思 |
| 2 | 想起来了但很费力 | 经过思考才回忆起来 |
| 3 | 有一定印象 | 能在选项中选出正确答案 |
| 4 | 比较熟悉 | 能较快回忆起含义 |
| 5 | 非常熟悉 | 瞬间反应，无需思考 |

**调度逻辑：**
- 评分 < 3：卡片重置为"学习中"，间隔重置为1天
- 评分 = 3：间隔不变，继续当前节奏
- 评分 > 3：间隔按 easeFactor 增长
- easeFactor 根据评分动态调整（2.5为基准，最低1.3）

**游戏结果映射到评分：**
- 拼写挑战正确 → 5分
- 配对/选择正确且快速 → 4分
- 配对/选择正确但较慢 → 3分
- 选择错误但后来纠正 → 2分
- 完全错误 → 0分

#### 2.3.3 动态调整策略
- **难度自适应**：连续答对的卡片减少出现频率，连续答错的增加频率
- **薄弱项聚焦**：自动识别薄弱领域（如某类短语总是记不住），优先推送
- **新卡节奏控制**：每日新卡数量根据用户近期复习完成率动态调整
- **疲劳检测**：连续错误过多时，自动降低难度或建议休息

| 冲突处理 | 导入数据与现有数据冲突时，提示用户选择保留哪个 | P1 |

#### 2.5.3 用户角色说明

| 角色 | 说明 | 权限 |
|------|------|------|
| 普通用户 | 通过手机号验证码登录的普通使用者 | 使用AI功能（受次数限制）、查看个人信息、购买次数 |
| 管理员 | 后端数据库标记的管理员账号 | 拥有普通用户所有权限，额外可查看用户列表、为用户充值AI次数 |

**管理员配置方式：**
- 管理员身份存储在后端数据库 `users.is_admin` 字段
- 初始管理员通过后端脚本或数据库直接设置
- 客户端登录后，后端接口返回 `isAdmin` 字段，客户端据此显示管理入口

#### 2.5.4 登录流程

```
手机号验证码登录流程：

1. 用户输入手机号，点击"获取验证码"
2. 客户端调用后端 POST /api/auth/send-code 接口
3. 后端调用阿里云短信服务发送6位验证码
4. 后端将验证码存入Redis（5分钟过期）
5. 用户输入验证码，点击"登录"
6. 客户端调用后端 POST /api/auth/login 接口
7. 后端校验验证码，查询/创建用户
8. 后端生成JWT Token返回给客户端
9. 客户端保存Token，登录成功
```

**验证码规则：**
- 6位纯数字验证码
- 有效期5分钟
- 同一手机号60秒内不可重复发送
- 同一手机号每天最多发送10次
- 验证码校验失败3次后失效，需重新获取

## 4. 非功能性需求

| 需求 | 说明 |
|------|------|
| 离线可用 | 核心功能支持离线使用（卡片管理、游戏、复习），多模态图片识别和AI分析需联网 |
| 响应速度 | 图片识别 < 10秒，页面切换 < 300ms |
| 数据安全 | 本地数据加密存储，支持导入导出防止数据丢失；API密钥支持配置文件默认值与用户自定义覆盖双源配置 |
| 存储优化 | 图片压缩存储，单张 < 500KB |
| 数据可迁移 | 支持完整数据导出和导入，换机不丢失学习进度 |
| 多平台支持 | 支持 Android、iOS、Windows桌面、Web 四个平台 |
| Web平台适配 | Web平台使用WasmDatabase.open替代NativeDatabase；图片使用blob URL而非本地文件路径；不支持本地通知；多模态模型识别图片需CORS代理 |
| CORS代理 | Web版支持CORS代理配置，解决浏览器跨域限制，用户可在设置页面配置代理地址 |
| 用户数据安全 | 用户手机号等敏感信息加密存储，JWT Token安全保存，敏感信息不明文保存在客户端 |
| 付费安全 | AI使用次数变更仅限管理员操作，客户端不可篡改；次数扣减采用服务端校验，防止本地篡改绕过限制 |

## 5. 后续扩展方向

- 多人PK模式：与好友在线对战
- AI 口语练习：语音识别 + 发音评分
- 学习社区：分享卡片集和学习心得
- 多语言支持：扩展到日语、法语等
- 云同步：自动同步到云端，多设备无缝切换
- Web平台能力补全：实现Web端标记检测能力、Web推送通知替代本地通知
- 自定义解析模板：保存常用解析要求组合为模板，一键复用
- 解析历史与偏好学习：根据用户历史选择的自定义要求，智能推荐解析方式
- 在线支付集成：接入微信支付/支付宝等在线支付方式，实现用户自助购买和自动充值
- 自动充值系统：付款成功后自动增加AI使用次数，无需管理员手动操作
- 第三方登录扩展：支持微信登录、Apple ID登录等第三方登录方式
